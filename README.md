# 🎮 Tic Tac Toe Game 💜💜

A classic **Tic Tac Toe** game built using pure **HTML, CSS & JavaScript**.

## 🚀 Features
- 2 Player mode
- Win & Draw detection
- Restart game option
- Clean and responsive UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## 🎯 How to Play
1. Two players take turns — X and O
2. First to get 3 in a row wins!
3. Click Restart to play again
